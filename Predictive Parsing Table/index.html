LL(1) Parse Table Generator

Construct Predictive Parsing Tables using FIRST and FOLLOW sets.

Input Grammar
Algorithm Rules:
1. For $A \rightarrow \alpha$, add to $M[A, a]$ for all $a \in FIRST(\alpha)$.
2. If $\epsilon \in FIRST(\alpha)$, add to $M[A, b]$ for all $b \in FOLLOW(A)$.
Syntax Guidelines
  • -> separates LHS and RHS.
  • | separates multiple productions.
  • Tokens MUST be space-separated (id + T).
  • e, eps, or ε represent Epsilon.
