Input Grammar
Algorithm Note: For Operator Grammars, LEADING and TRAILING sets search for the first/last terminal. They look past a single leading or trailing non-terminal if necessary to find it.
Syntax Rules
  • Use -> to separate LHS and RHS.
  • Use | to separate multiple productions.
  • Separate all tokens (terminals and non-terminals) with spaces (e.g., E + T).
  • Operator grammars generally do not use Epsilon (ε).
