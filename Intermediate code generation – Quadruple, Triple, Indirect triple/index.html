Intermediate Code Generation

Translates statements into Quadruples, Triples, and Indirect Triples.

Source Statements
The Three Forms:

• Quadruples: Uses temporary variables (e.g., $t_1, t_2$) to store intermediate results. Fields: (Op, Arg1, Arg2, Result).

• Triples: Avoids temporary variables by directly referencing the instruction index (e.g., (0)). Fields: (Op, Arg1, Arg2).

• Indirect Triples: Uses an array of pointers to the Triples. Extremely useful for optimizing compilers because instructions can be reordered by moving pointers rather than modifying the triples themselves.
